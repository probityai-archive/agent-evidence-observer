In bucket (more_itertools/more.py) the validator is now stored as given and every check goes through a new _is_valid() helper that treats only None as 'no validator', instead of replacing any falsey validator with an accept-all lambda via 'or'. A callable that is falsey, such as an empty set subclass with __call__, is therefore honoured in __contains__, __getitem__, __iter__ and the cache-filling loop.
